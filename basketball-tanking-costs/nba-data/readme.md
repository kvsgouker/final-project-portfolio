Files in "games" folder are from a game history source.

### Background Notes.

* Most of the data is stored in nba_data.db.
* There are new tables in the games folder.
* Salary data was also scraped and added.

### File Information

* championships_table.csv - scraped from wikipedia
* extended_game_history.csv - games with lagging data
* fan_attendance.csv - from games data, all attendance for all seasons
* fan_attendance_revenue.csv - from run-repeat - 2011-2021 includes revenue
* league_mapping.csv - league parameters
* market_size.csv - information about market_size for q & a.
* nba_player_records.csv - all nba records
* player_salaries.csv - salaries and divisions
* team_mapping.csv - for franchise location
* TeamRevenue.csv - Essentially all original data from run-repeat. Only used in preprocessing

### Source

* TeamRevenue.html - original file was java script so saved here.
* championships.html - downloaded from wikipedia
