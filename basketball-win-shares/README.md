# The Statistical Reality of the NBA Draft

## Instructions
Regarding the two IPYNB files:
* NBA-Research is for web-scraping data into an SQL database
* SalgadoGouker-basketball-win-shares does the basketball analysis on top of an SQL database

Otherwise:
- Download code
- Open Jupyter Notebook
- Some functions may require internet access

## Tools & Dependencies

This project was developed using the following tools:

- Jupyter Notebook
- Python 3.8 or later
- matplotlib
- pandas
- numpy
- tabulate
- Image
- ImageDraw
- ImageFont
- thinkstats2
- thinkplot
- sqlite3
