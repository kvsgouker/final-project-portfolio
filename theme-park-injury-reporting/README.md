# Standardizing Injury Reporting in U.S. Theme Parks: A Data Science Approach

## Instructions

- Download code
- Open PyCharm
- Create new project with existing source at root of code base
- Use "main" as initial script. A menu will appear.
- Some functions may require internet access

This project was developed using the following tools:

- PyCharm
- Python 3.8 or later
- matplotlib
- pandas
- numpy
- seaborn
- scikit-learn
- statsmodels
- requests
- tabulate
- beautifulsoup4
- lxml
